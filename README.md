# Personal Developer Portfolio

* Responsive Design
* Smooth Page Animations
* Interactive Project Showcase
* Contact Form with Resend
* SEO Optimized
* Custom Domain Support
* Vercel Deployment

## Tech Stack

* Next.js

* TypeScript
* Tailwind CSS
* Framer Motion
* Resend
* Vercel
